4. تشغيل Claude Code في الطرفية

أول مرة (المجلد الجديد)

cd ~/montnero-store git pull claude

الرسالة الأولى (جرد الأدوات)

اقرأ product_audit/TERMINAL_PROMPT.md ونفّذه حرفياً. ابدأ بالخطوة 0: اجرد كل الأدوات والمهارات والإضافات والموصلات المتاحة لك وأخبرني بها، ثم انتظر كلمة ابدأ مني قبل أي عمل.

بعد أن يعرض الأدوات اكتب ابدأ. يكمل A001 ثم A002 وما بعدها بلا أسئلة، ويبني تقرير HTML بعد كل دفعة.

الاستئناف بعد انقطاع أو في اليوم التالي

cd ~/montnero-store git status --short | head git pull claude --continue

إن بدأت جلسة جديدة بلا سياق اكتب:

تابع. اقرأ product_audit/TERMINAL_PROMPT.md ثم BATCH_PROGRESS.md، ونفّذ التشغيل المستقل من حيث وقف العمل دون إعادة ما اكتمل. إن وُجدت ملفات غير محفوظة في git فاحفظها وادفعها أولاً.

النموذج والصلاحيات

  • النموذج: /model sonnet للجلسة والوكلاء. Opus للمراجعة النهائية فقط. تجنب Haiku وGemini Flash لهذا العمل.
  • أبق وضع الصلاحيات التلقائي أثناء التشغيل المستقل (بدّل بـ Shift+Tab). لا تستخدم --dangerously-skip-permissions مع root.
  • لا يرفع Claude Code إلى سلة. الرفع من صفحة المزامنة التي تفتحها أنت.

5. سير الدفعة (200 منتج)

  1. بحث بالباركود والاسم ثم موقع الماركة والموزعين، وتثبيت الاسم والحجم والدرجة.
  2. صور إضافية (حتى 5) تُفحص بصرياً قبل اعتمادها.
  3. كتابة الحقول لكل منتج على حدة (وكلاء sonnet ~20 منتجاً لكل وكيل).
  4. render_desc.py حتى «0 with problems»، ثم مراجعة وتنويع الجمل المتكررة.
  5. بناء ملف ميرشنت build_merchant.py وصفحة المزامنة make_sync_page.py ونشرها بالرابط نفسه.
  6. أنت تشغّل الصفحة، ثم يقرأ Claude النتائج ويملأ الرابط والصورة في ميرشنت.
  7. تقرير HTML بعد الدفعة، حفظ ودفع إلى GitHub، ثم الدفعة التالية.
